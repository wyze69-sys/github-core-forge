A standalone GitHub-compatible git forge in one Node process, with its own object store and no git binary: git smart HTTP (protocol v2 upload-pack with ls-refs and shallow fetch, v0 receive-pack pushes), the REST v3 API, GraphQL with introspection and Relay node ids, and an MCP endpoint, all reading and writing one shared in-memory store. A logical clock keeps every run deterministic.

## Run it

```sh
node main.ts
```
